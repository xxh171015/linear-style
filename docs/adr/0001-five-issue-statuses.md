# Five Issue statuses, not named workflow states

Linear gives each Team a set of named WorkflowStates whose type is one of seven categories. This replica collapses that to five Issue statuses (`backlog`, `todo`, `progress`, `done`, `canceled`): one status per user-creatable type, no triage, no duplicate. Named-state multiplicity is too heavy for a single-team personal replica, and triage is already out of this map’s destination.
