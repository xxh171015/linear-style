# Built-in lists are queries; Project membership is not a Custom View

A Project’s Issues tab is the Issues that belong to that Project. A Custom View whose filter names a Project is a different, saved query. My Issues and Team Issues are built-in lists, not Custom Views. Grouping and layout use one vocabulary: stored on a Custom View, ephemeral on a built-in list. An Issue keeps one identity across every list; a Milestone is allowed only while the Issue belongs to that Milestone’s Project.
